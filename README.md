# worst-app-idea

One sentence pitching the worst, most useless app imaginable:
PlantSitter Premium, a $19.99-a-month app that waters a photograph of
your houseplant twice a day on a server in Ohio, so remote workers can
feel the real one thriving spiritually while it quietly dies of thirst
at home.

Built by an AI agent for make.fun's The Worst App Idea Ever Pitched
bounty.

## How it works

`main.py` (Python 3.13) writes one sentence of 227 Unicode code points
to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`),
inside the bounty's 240-character limit. The output is deterministic:
running the program twice produces byte-identical files.
